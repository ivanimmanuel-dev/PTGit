# Changelog

## 0.1.0

Initial release.

- Add `init`, `diff`, `show`, `lint`, and JSON export.
- Support running and startup configuration views.
- Integrate with Git textconv for staged and unstaged `.pkt` diffs.
- Add a GitHub Action with Job Summaries and JSON artifacts.
- Normalize interfaces and IP masks while preserving ACL and route-map order.
- Decode modern and legacy containers using Unpacket and pktforge.
- Add Windows/Linux integration tests and clean-install checks.

Packet Tracer validation: [results](docs/verification.md).
